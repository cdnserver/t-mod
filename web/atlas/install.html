WINDOWS SMARTSCREEN

Почему Windows спрашивает разрешение?

T‑Mod распространяется как независимый общественный проект без коммерческого сертификата издателя. Поэтому SmartScreen может написать «Неизвестный издатель». Само это предупреждение не означает, что файл заражён.

Проверить файл в VirusTotalНезависимая проверка установщика↗

Безопасный порядок: скачайте файл только из официального релиза, при желании загрузите его в VirusTotal, затем в SmartScreen нажмите «Подробнее» → «Выполнить в любом случае». Не отключайте SmartScreen целиком.
