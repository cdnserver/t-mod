# Синхронизация GitBook и GitHub

Публичная документация TXSG хранится в каталоге `gitbook/`. Каталог `docs/` остаётся технической документацией репозитория и не публикуется в пользовательский GitBook.

## Первичная выгрузка опубликованных страниц

Скрипт читает полный индекс `llms.txt`, загружает каждую Markdown-страницу, убирает служебное приложение GitBook для AI-агентов и переводит внутренние ссылки в относительные:

```bash
python scripts/sync_gitbook_docs.py --write
```

Без `--write` скрипт ничего не меняет и только проверяет расхождения:

```bash
python scripts/sync_gitbook_docs.py
```

Файл `gitbook/.source-manifest.json` хранит адрес и SHA-256 каждой выгруженной страницы. Он не содержит токенов или других секретов.

## Подключение штатного Git Sync

После проверки файлов и отдельного коммита:

1. Открыть пространство TXSG Docs в GitBook и выбрать **Configure → GitHub Sync**.
2. Авторизовать GitBook GitHub App для репозитория `cdnserver/t-mod`.
3. Выбрать репозиторий `cdnserver/t-mod` и ветку `main`.
4. В качестве начального направления выбрать **GitHub → GitBook**.
5. Запустить первичную синхронизацию.

GitBook прочитает `.gitbook.yaml` в корне репозитория и возьмёт страницы из `gitbook/`. После первичного подключения синхронизация работает в обе стороны: коммиты GitHub появляются в GitBook, а объединённые изменения GitBook создают коммиты в выбранной ветке.

После включения Git Sync скрипт импорта больше не является основным механизмом синхронизации. Он остаётся только инструментом проверки опубликованного источника; повторный запуск с `--write` может перезаписать локальные правки опубликованной версией.
