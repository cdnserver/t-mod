# Telegram и Atlas

Telegram-контур включается только если в приватном `.env` бота задан
`TELEGRAM_BOT_TOKEN`. Токен не хранится в репозитории и не попадает в логи.

## Первичная настройка

1. В `.env` на сервере добавьте `TELEGRAM_BOT_TOKEN` и, по желанию,
   `TELEGRAM_BOT_USERNAME` (без `@`). Оставьте `TELEGRAM_POLLING_ENABLED=true`.
2. Перезапустите только `tmod-discord-bot`.
3. Пользователь открывает личный Реактор → **Подключения** → **Telegram ·
   Atlas** и нажимает «Подключить».
4. Реактор создаёт короткую ссылку. Кнопка открывает Telegram и завершает
   привязку автоматически; ручной запасной вариант — отправить боту
   `/link КОД`. Код одноразовый и действует 10 минут.

Команда `/tg-link` в личных сообщениях T‑Mod — быстрый способ для любого
пользователя, в том числе не-сенатора: она выдаёт код и готовую ссылку на
Telegram. Команда `/telegram-link` на сервере Discord также остаётся резервным
способом для участников Товарищества.

После привязки открывается постоянное меню на inline-кнопках. В нём можно
посмотреть профиль и персонажей, проверить уведомления и баланс Atlas Token,
открыть историю диалогов и продолжить выбранную переписку. Контекст каждого
личного Telegram-чата хранится в том же Atlas-хранилище, что и веб/Discord
диалоги. Кнопка «Новый диалог» закрывает только текущую ветку в Telegram —
старая история не удаляется.

Переходы между разделами обновляют текущую панель, не засоряя чат. Если аккаунт
ещё не подключён, главное меню сразу показывает кнопку перехода в Реактор.

В меню есть кнопка «Код входа в T‑Mod». Она выдаёт восьмизначный код на 5 минут
для уже привязанного Telegram-профиля. Код действует один раз, новый код
отменяет предыдущий, в базе хранится только его хеш. На странице входа выберите
«Войти через Telegram» и введите код; в сообщении есть кнопка быстрого
копирования PIN. Код автоматически удаляется из чата по истечении срока. Это не создаёт новый аккаунт и не
повышает права: применяются обычные ограничения T‑Mod и глобальной блокировки.

Личные сообщения, которые сам T‑Mod отправляет этому Discord-аккаунту,
дублируются в привязанный Telegram-чат. Переносятся текст, содержимое embed и
ссылки кнопок. Вложения остаются в Discord; в Telegram указывается их имя.
Сообщения в каналах и групповых чатах не зеркалируются.

Права не расширяются: глобальная блокировка, отзыв `atlas_ai` или отсутствие
доступа сразу закрывают запросы в Telegram.

Для удаления привязки владелец аккаунта выполняет `/telegram-unlink` в Discord.
Повторная выдача кода безопасно заменяет старую привязку этого Discord-аккаунта;
один Telegram-профиль одновременно не может принадлежать двум аккаунтам.

## Команды бота

- `/start` или `/help` — краткая инструкция;
- `/link КОД` — одноразовая привязка;
- `/tg-link` в личке Discord — получить код и ссылку для привязки;
- `/atlas вопрос` — Atlas с обычным режимом ответа;
- `/atlas2 вопрос` — текстовый прямой режим Atlas 2;
- `/profile` или `/account` — профиль T-Mod и персонажи;
- `/characters` — список подключённых персонажей;
- `/notifications` — уведомления Реактора;
- `/history` — история диалогов Atlas;
- `/loginpin` — временный код для входа в T‑Mod;
- `/read` — отметить уведомления прочитанными;
- `/usage` — тариф, баланс и расход Atlas Token;
- `/newchat` — начать новую ветку Atlas, сохранив историю;
- `/settings` — состояние подключения;
- `/stop` — выйти из режима общения с Atlas;
- `/telegram-link` и `/telegram-unlink` — только в Discord.

Бот принимает запросы только в личных чатах Telegram, чтобы ответы и данные
не раскрывались в группах.
