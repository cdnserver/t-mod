# case lifecycle

Кейс — это приватный канал, в котором находятся клиент, назначенные сотрудники и все материалы дела.

{% stepper %}
{% step %}
## Создание кейса

Сотрудник SGL:

1. Открывает командный центр.
2. Вводит `/sg user:@Клиент`.
3. Проверяет карточку клиента.
4. Нажимает **«Создать кейс»**.

Бот присваивает следующий номер, создаёт приватный канал и публикует приветственную карточку. Ведущий адвокат назначается из настроек Бюро, если сотрудник не выбрал другого.

{% hint style="info" %}
Клиенту не нужно самостоятельно создавать канал или выдавать кому-либо доступ. Разрешения настраивает бот.
{% endhint %}
{% endstep %}

{% step %}
## Заполнение параметров

В приветственном сообщении или панели `/sg` нажмите **«Параметры»**.

Дальше бот предложит:

1. Выбрать тип обращения.
2. Использовать ранее сохранённый профиль либо создать новый.
3. Указать игровой ник, статик, банковский счёт и телефон.
4. Добавить ссылку на паспорт или удостоверение.

Проверьте цифры перед отправкой — эти сведения будут подставляться в чек и договор.
{% endstep %}

{% step %}
## Описание ситуации

После параметров бот попросит развернуто описать обстоятельства.

Отправьте **одно обычное текстовое сообщение** в канале кейса. Укажите:

* что произошло;
* когда и где;
* кто участвовал;
* какие доказательства есть;
* какой результат ожидает клиент.

Бот сохранит следующее подходящее сообщение как описание ситуации и оформит его отдельной карточкой.

### Хороший пример

```
12 июля около 20:30 у здания суда сотрудник отказался принять заявление.
Свидетели: Имя Фамилия, статик 12345. Есть видеозапись и скриншот переписки.
Прошу оценить законность отказа и подготовить обращение.
```
{% endstep %}

{% step %}
## Работа сотрудника

После заполнения данных канал получает статус `👀`. Сотрудник изучает материалы, связывается с клиентом и готовит необходимые документы.

Для ежедневной работы достаточно вводить `/sg` в канале и выбирать нужную кнопку.
{% endstep %}

{% step %}
## Ссылка на иск

Когда иск или заявление готово:

1. Нажмите **«Добавить ссылку»**.
2. Вставьте полный адрес, начинающийся с `https://` или `http://`.
3. Подтвердите форму.

Бот сохранит ссылку, опубликует и постарается закрепить карточку. Канал перейдёт в состояние `🧘‍♂️`.
{% endstep %}

{% step %}
## Оплата и договор

Сотрудник создаёт чек, клиент отправляет ссылки на доказательства оплаты, а ведущий адвокат подтверждает поступление средств. После этого можно сформировать договор.

Подробная инструкция: [Чеки, оплата и договоры](/broken/pages/f0aec188dff92b85697bf63f02f4fa782210ab74).
{% endstep %}

{% step %}
## Закрытие кейса

Закрыть дело может ведущий адвокат, секретарь или администратор.

1. Откройте `/sg` в канале дела.
2. Нажмите **«Закрыть кейс»**.
3. Опишите итог понятным языком.
4. Выберите, нужна ли обезличенная публикация в портфолио.
5. Подтвердите закрытие.

Бот поставит значок `✋`, опубликует итог и запланирует перенос канала в архив. Обычно это происходит через 24 часа.
{% endstep %}
{% endstepper %}

## Что проверить перед закрытием

```
□ Данные клиента заполнены
□ Описание ситуации сохранено
□ Ссылка на иск добавлена, если она была нужна
□ Оплата подтверждена
□ Договор сформирован, если он требовался
□ Итог дела написан без персональных данных для портфолио
```

## Если открыли не тот кейс

Не удаляйте канал вручную. Откройте карточку через `/sg case:<номер>` и передайте номер ответственному сотруднику. Служебное удаление должно убрать не только канал, но и связанные записи.
