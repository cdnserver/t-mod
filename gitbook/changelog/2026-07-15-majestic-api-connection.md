# 15 июля 2026 — подключение Majestic API

T-Mod получил первое рабочее подключение к данным Majestic для сервера **RU15 · Phoenix**.

## Что уже работает

* в `#тест-бота` появилась кнопка **«Проверить Majestic»**;
* результат проверки видит только запустивший её администратор;
* бот показывает доступность API, число товарных позиций и свежесть рыночной статистики;
* повторные проверки используют кэш и не расходуют лимит запросов без необходимости;
* API-ключ не публикуется в Discord и не записывается в GitHub.

## Чего пока нет

Рыночные цены ещё не участвуют в расчётах мастерской. Следующий этап — сопоставить предметы
Majestic с материалами и изделиями T-Mod, после чего добавить расчёт себестоимости крафтов.

{% hint style="info" %}
Обычным участникам ничего настраивать не нужно. Подключение API выполняется администратором на
домашнем сервере T-Mod.
{% endhint %}
