# 2 августа 2026 — упрощение медиаконтура

T-Mod больше не подключает отдельный пользовательский Discord-клиент и не показывает экран от
имени тестового аккаунта. Команда `/screen`, внутренний сервис управления и кнопки браузерной
демонстрации удалены.

Обычная музыка, голосовое управление и все веб-панели продолжают работать. Страница
`zigmund.tvr.lat` тоже остаётся доступной как самостоятельная веб-страница.

При первом запуске новой версии стандартный Windows-батник автоматически удалит старые контейнер,
образ, профиль Chromium и отдельный файл настроек клиента. Отдельно очищать Docker или оставшийся
токен не требуется.

## Исправления

Восстановление веб-доступа через `/reset` теперь всегда завершается отдельным личным ответом.
Если Discord успел удалить исходное временное сообщение, бот безопасно создаёт новую панель и не
отменяет уже сохранённый логин или PIN.

При достижении лимита Majestic API бот соблюдает время `Retry-After`, приостанавливает оставшиеся
запросы текущего цикла и продолжает обслуживать поиск по последнему сохранённому каталогу без
аварийной трассировки.

Управление Minecraft в «Ядерном Реакторе» больше не держит веб-запрос открытым до полной
остановки или перезапуска сервера. Команда подтверждается сразу, выполняется безопасно в фоне, а
панель показывает промежуточное состояние и сама следит за завершением. Повторный клик не создаёт
вторую операцию. Проверка RCON вынесена из общего снимка Реактора, поэтому недоступный Minecraft
не замедляет казну, аудит, центр внимания и остальные разделы.

Обычный запуск T-Mod теперь также не останавливает Minecraft без причины: новый контейнер игрового
сервера создаётся только при первом запуске, изменении его конфигурации или восстановлении секрета.
Обновления бота и веб-панели применяются без лишнего разрыва игрового соединения.

## Production-аудит T-Mod

Старые обработчики СГЛ, постоянного архива, финансов и операционного центра больше не выполняют
запросы к SQLite прямо в основном цикле Discord. Даже если база занята обслуживанием или большим
архивом, музыка, кнопки, команды и ответы бота продолжают обрабатываться. Отдельная архитектурная
проверка не позволит случайно вернуть блокирующий запрос в будущих обновлениях.

Скрытые вкладки Консенсуса и Ядерного Реактора теперь полностью приостанавливают периодические
запросы и корректно закрывают таймеры и поток событий при уходе со страницы. После возвращения
панель сразу получает свежий снимок. Загрузка больших плагинов Minecraft и публикация изображений
также вынесены из общего цикла, поэтому они не замедляют остальные веб-команды.

Веб-интерфейсы получили единый локальный комплект Manrope и Unbounded: шрифты не зависят от
системы или браузера, кириллица выглядит одинаково в Chrome, Яндекс Браузере и на мобильных
устройствах. Проверяются уникальность элементов, целостность ресурсов, минимальный читаемый размер
текста и горизонтальное переполнение.

Контейнер T-Mod теперь работает без прав root. Caddy ждёт готовности веб-сервера, ограничивает время
ожидания зависшего backend и добавляет политику браузерных разрешений. При этом неисправность
Minecraft Supervisor больше не блокирует запуск Discord-бота и остальных сайтов. Название игрового
сервера в списке Minecraft приведено к единому стилю T-Mod.

Пакет XML обновлён до безопасной ветки `lxml 6.1`, а автоматическая проверка сборки теперь включает
аудит известных уязвимостей, целостность зависимостей, Ruff, компиляцию всех Python-модулей и
проверку синтаксиса каждого браузерного JavaScript-файла.

## Автоматический Error Inbox

Runtime-ошибки T-Mod теперь сохраняются в надёжную локальную очередь и могут автоматически
публиковаться в закрытые GitHub Issues. Одинаковые трассировки объединяются, повторы считаются, а
закрытый Issue открывается снова, если исправленная ошибка вернулась. Перед отправкой из отчёта
удаляются известные токены, пароли, API-ключи и приватные ключи.

Недоступность GitHub не влияет на бота: отчёт остаётся в SQLite и отправляется позже с безопасной
задержкой. Для публикации используется отдельный fine-grained token только с правом `Issues: write`;
доступ к исходному коду боту не предоставляется. Для разработчика добавлена команда выгрузки всех
открытых отчётов в один локальный Markdown-файл.
