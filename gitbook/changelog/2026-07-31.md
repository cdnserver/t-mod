# 31 июля 2026 — Minecraft Paper на mc.tvr.lat

Штатный Windows-запуск T-Mod теперь поднимает отдельный Minecraft Java сервер в Docker. Сервер
использует Paper `26.1.2` build `74`, образ `itzg/minecraft-server:java25-jdk` и `4G` памяти.

Игровой мир, плагины и настройки сохраняются вне репозитория:

```text
C:\Users\Admin\Documents\SGLDiscordBot\minecraft
```

Запускатор создаёт постоянную папку, открывает в Windows Firewall порт `25565/TCP` и стартует
контейнер `minecraft` вместе с остальными сервисами Docker Compose.

Для подключения игроков администратору нужно отдельно направить DNS-запись `mc.tvr.lat` на
публичный IPv4 домашнего сервера и пробросить на роутере:

```text
TCP 25565 → сервер:25565
```

Caddy и HTTPS для Minecraft не используются: Minecraft Java подключается напрямую к игровому
TCP-порту.
