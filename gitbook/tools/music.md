# T-Mod Music и голосовое управление

В категории **«Администрирование TVRS»** бот автоматически создаёт канал **«музыкальный-центр»**
с одной общей панелью. Она показывает текущее подключение, композицию, очередь и состояние
голосового управления. Все видят одну и ту же карточку, но ответ на любое нажатие получает лично
нажавший: общий канал не превращается в ленту служебных сообщений.

Панель проверяет состояние каждую секунду и сама восстанавливается после перезапуска или удаления
сообщения. Если состояние не изменилось, T-Mod не отправляет лишний запрос в Discord; это сохраняет
секундную реакцию без ограничений `429`. Старая карточка из случайного канала запуска больше не
создаётся. `/music` по-прежнему доступна в любом текстовом канале и открывает дополнительную личную
панель того же музыкального сеанса.

## Быстрый запуск

1. Зайдите в голосовой канал.
2. Откройте **«музыкальный-центр»** или выполните `/music`.
3. Нажмите **«Подключить»** — результат будет виден только вам.
4. Нажмите **«Включить»** и введите русское название композиции либо ссылку `youtube.com` / `youtu.be`.

Поиск берёт один наиболее подходящий результат. Ссылки на другие сайты и локальные адреса
отклоняются. T-Mod не сохраняет композиции в постоянной папке: `yt-dlp` получает метаданные и
временный аудиопоток, который передаётся в Discord через FFmpeg.

## Кнопки

| Кнопка | Действие |
| --- | --- |
| **Подключить** | Подключить T-Mod к вашему текущему голосовому каналу |
| **Голос для меня** | Персонально включить или выключить распознавание ваших голосовых команд |
| **Голосовая команда** | После сигнала принять одну команду без ключевой фразы |
| **Включить** | Найти композицию или добавить ссылку YouTube |
| **Пауза / Продолжить** | Приостановить или возобновить текущий поток |
| **Следующая** | Пропустить текущую композицию |
| **Стоп** | Остановить музыку и очистить очередь |
| **Тише / Громче** | Изменить общую громкость шагом 10% |
| **Очередь** | Показать до 20 следующих композиций |
| **Отключить** | Покинуть войс; доступно подключившему бота и управляющим сервером |

Управлять воспроизведением можно только из того же голосового канала. Если в канале не останется
людей, T-Mod отключится автоматически после настроенного периода ожидания.

## Голосовое управление

Голосовое управление включается персонально кнопкой **«Голос: включить»**. После этого:

1. Скажите **«Банан»**, **«Сборщик риса»** или **«Т-Мод»**.
2. Дождитесь короткого звукового сигнала.
3. В течение восьми секунд произнесите команду.

Можно также произнести всё одной фразой: **«Банан, включи Кино Группа крови»**.
Для короткого обращения варианты **«т мод»**, **«тимод»** и **«ти мод»** также распознаются.

Если не хочется использовать обращение, нажмите **«Голосовая команда»**, дождитесь сигнала и
скажите, например, **«играй Цой»**. Если постоянный режим «Голос: включить» был выключен, T-Mod
примет только эту команду и автоматически прекратит обработку после выполнения или тайм-аута.

T-Mod сначала использует быструю модель распознавания. Перед отправкой бот отсекает тишину,
выравнивает слишком тихий микрофон и передаёт компактный речевой WAV. Если обращение или команда
получились неоднозначными, только эту фразу одновременно перепроверяют две точные модели; первый
корректный результат используется сразу. Поэтому обычные команды отвечают быстро, а сложная или
шумная речь получает дополнительный шанс без удвоения каждого запроса.

Команды после сигнала имеют приоритет над фоновыми фразами. Речь разных участников может
распознаваться одновременно, но порядок фраз одного человека всегда сохраняется. Если ни одна
модель не поняла активную команду, прозвучит короткий нисходящий сигнал: команду можно сразу
повторить, не нажимая кнопку и не произнося обращение заново.

Поддерживаются команды:

* «включи / поставь / найди / проиграй *название*»;
* «пауза», «продолжи», «следующая», «стоп»;
* «громче», «тише», «громкость 50 процентов»;
* «что играет», «покажи очередь», «отключись».

OpenRouter используется только для преобразования русского аудио в текст. Действие выбирает
локальный строгий парсер: языковая модель не управляет ботом и не создаёт произвольные команды.

## Приватность

T-Mod обрабатывает речь только пользователя, который сам включил голосовое управление для себя.
Пакеты остальных участников сразу игнорируются и не передаются в STT. Фрагменты держатся в оперативной памяти до
распознавания, не сохраняются в SQLite или на диск и не публикуются в Discord. Отключение
персонального режима немедленно очищает незавершённый буфер этого пользователя; уже извлечённый
из очереди запрос невозможно отозвать у внешнего API.

Распознавание выполняется через
[OpenRouter Speech-to-Text](https://openrouter.ai/docs/guides/overview/multimodal/stt) и расходует
баланс API согласно выбранным моделям. В стандартной конфигурации быстрый проход выполняет OpenAI,
а неоднозначную фразу могут проверить OpenAI и Qwen. Чтобы разрешить только OpenAI, укажите
`MUSIC_STT_FALLBACK_MODELS=openai/gpt-4o-transcribe`.

## Надёжность

Обычная музыка и кнопки не зависят от распознавания речи. Discord-приём аудио реализован через
изолированный адаптер `discord-ext-voice-recv`. Если этот экспериментальный компонент перестанет
подключаться после изменения Discord, T-Mod повторит подключение в обычном режиме: музыка
останется доступна, а голосовая кнопка объяснит причину недоступности.

T-Mod снимает голосовое DAVE/E2EE-шифрование через активную сессию `discord.py`, затем декодирует
Opus отдельно для каждого говорящего. Единичный повреждённый пакет отбрасывается без остановки остальных участников. При другом внутреннем сбое приёмник делает
до трёх автоматических восстановлений; это не перезапускает музыку и не очищает очередь.

Для воспроизведения контейнер включает FFmpeg, голосовые зависимости `discord.py`, `yt-dlp` и
закреплённую версию voice-receive. При изменении зависимостей нужно пересобрать Docker-образ —
штатный `run_windows.bat` делает это автоматически.
