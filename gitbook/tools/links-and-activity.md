# links and activity

## Полезные ссылки

Ссылки можно получить двумя способами.

### Через Универсалитет

Откройте `/tvrs` → **«Ссылки»**. Появятся кнопки доступа к Бюро и заявки в Товарищество.

### Быстрой командой

Подойдут все варианты:

```
/l
/link
/л
/линк
```

Ответ приватный. Также бот понимает текстовые варианты `.l`, `.link`, `.ссылка` и `.ссылки`. Для них он попробует отправить ссылки в ЛС и поставить реакцию ✅. Если ЛС закрыты, ответ временно появится в канале.

## Отчёт об активности

Команда `/activity` помогает понять, когда роль или конкретный пользователь в последний раз участвовали в жизни сервера.

### Режимы

| Режим  | Что показывает                    |
| ------ | --------------------------------- |
| `all`  | Все доступные виды активности     |
| `tvrs` | События пространства Товарищества |
| `sgl`  | События, связанные с SGL Bureau   |

### Активность роли

Введите:

```
/activity type:tvrs
```

Затем выберите Discord-роль. Бот покажет участников от самых давно неактивных к самым активным.

### История пользователя

```
/activity type:sgl user:@Участник
```

В отчёте будут последние доступные события с датой, каналом и кратким описанием.

## Как понимать отчёт

Активность — это ориентир, а не оценка человека. Отсутствие событий может означать, что:

* участник работал до начала сбора истории;
* действие не относится к выбранному режиму;
* отдельный вид событий не отслеживается;
* работа проходила вне доступных боту каналов.

{% hint style="warning" %}
Не используйте один отчёт как единственное основание для кадрового или дисциплинарного решения. Сначала уточните контекст у участника.
{% endhint %}

Ответ `/activity` приватный и не публикует список в общий канал.
