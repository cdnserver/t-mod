# ai

Бот предоставляет два творческих инструмента: SGL Audio и Zigmund AI. Доступ зависит от роли и выделенного командного канала.

## SGL Audio

Команда `/sglaudio` создаёт аудио по текстовому описанию.

### Как заказать

1. Перейдите в разрешённый канал.
2. Введите `/sglaudio`.
3. Опишите стиль, настроение, темп, инструменты и назначение аудио.
4. Отправьте форму и дождитесь завершения.

Пример запроса:

```
Торжественный оркестровый марш без вокала, уверенный темп, медные духовые
и барабаны. Подходит для церемонии, длительность около одной минуты.
```

Генерации выполняются по очереди. Приватный статус показывает ожидание и ход работы, а готовый файл публикуется в выделенном канале.

{% hint style="info" %}
Не отправляйте команду повторно, если статус долго не меняется. Генерация аудио может занимать несколько минут.
{% endhint %}

## Zigmund AI

Команда `/zigmund` создаёт изображение по описанию.

1. Введите `/zigmund` в разрешённом канале.
2. Опишите сцену, композицию, стиль, свет и желаемые детали.
3. Дождитесь приватного предварительного результата.
4. Нажмите **«Отправить в общий чат»**, только если изображение подходит.

Кнопку публикации может нажать только автор запроса.

### Пример хорошего описания

```
Официальная эмблема юридического бюро: весы правосудия, тёмно-синий фон,
серебряные линии, строгая симметрия, чистый минимализм, без мелкого текста.
```

## Правила безопасного запроса

* не вставляйте в промпт паспортные данные, телефоны и закрытые материалы кейсов;
* не выдавайте AI-результат за доказательство или официальный документ;
* проверяйте текст, символы и детали перед публичной отправкой;
* не запускайте несколько одинаковых генераций подряд;
* соблюдайте правила Discord и сервера.

## Если результат не появился

Подождите несколько минут и проверьте приватный статус. Если бот сообщил об ошибке, попробуйте сформулировать запрос короче. При повторной ошибке передайте ответственному время запуска и ID генерации, если он отображается.
