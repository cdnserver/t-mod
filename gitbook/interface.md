# interface

Бот использует несколько повторяющихся элементов. Понимая их, легче ориентироваться в любой системе.

## Приватная панель

Пометка **«Видно только вам»** означает, что панель служит вашим пультом управления. Другие люди не видят её и не могут нажать кнопки.

## Общая карточка

Общая карточка — единый источник актуального состояния для команды. Так выглядят законопроекты, планы крафтов, чеки, итоги голосований и карточки кейсов.

Не создавайте новую карточку только потому, что старая находится выше в канале. Используйте **«Обновить»** или актуальные кнопки на существующем сообщении.

## Частые обозначения

| Значок | Обычно означает                                    |
| ------ | -------------------------------------------------- |
| ✅      | Подтверждено, принято или завершено успешно        |
| ❌      | Отклонено, не подтверждено или действие невозможно |
| ⏳      | Ожидание данных, голоса или следующего этапа       |
| 🔄     | Обновить данные                                    |
| ↩️     | Вернуться или отменить действие                    |
| 🔍     | Поиск или сверка                                   |
| 🧾     | Журнал, чек или аудит                              |

## ID действия

После важных операций бот показывает номер вида `#184`. Это ID действия, а не сумма и не номер кейса. По нему можно найти запись в аудите или отменить точное действие.

## Номера разных систем

| Вид                    | Пример |
| ---------------------- | ------ |
| Законопроект           | `011`  |
| Кейс SGL               | `090`  |
| План крафта            | `#7`   |
| Финансовая запись      | `#152` |
| Универсальное действие | `#184` |

Читайте заголовок карточки, чтобы не перепутать номер проекта, плана и действия.

## Кнопка неактивна

Серая или недоступная кнопка обычно означает, что:

* действие уже выполнено;
* сначала нужен предыдущий этап;
* идёт производственный цикл или пауза;
* действие доступно только ответственному;
* карточка устарела.

Откройте свежую панель через `/tvrs` или `/sg`, если состояние кажется неверным.

## Ссылочные кнопки

Кнопки **«Открыть канал»**, **«Открыть иск»**, **«Перейти к подаче»** не изменяют данные — они просто переводят в нужное место.
