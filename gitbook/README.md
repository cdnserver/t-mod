# README

Добро пожаловать в справочник T-Mod — Discord-бота Товарищества и SGL Bureau.

Здесь нет описаний кода, внутренних схем и настроек сервера. Каждая страница отвечает на практический вопрос: **что нажать, что заполнить, что произойдёт дальше и как исправить ошибку**.

{% hint style="info" %}
Главная точка входа Товарищества — постоянная карточка в `#панель-управления`; команда `/tvrs` открывает такое же личное меню в любом серверном канале. Для Бюро используется `/sg`.
{% endhint %}

## Что умеет бот

### 🏛️ Товарищество

* единое меню `/tvrs`;
* операционный центр без дублирования рабочих карточек;
* казна, ежедневные и внеплановые сверки;
* рецепты, закупки, производственные циклы, склад, маркет и продажи;
* прозрачный журнал, поиск операций, статистика и безопасная отмена;
* законопроекты, очередь, пленарные консенсусы, дискуссии и вето.

### ⚖️ SGL Bureau

* приватные клиентские кейсы;
* карточки клиентов и сотрудников;
* описание ситуации и ссылка на иск;
* чеки, подтверждения оплаты и договоры;
* реестры, новости, закрытие и архивирование дел.

### ✨ Общие инструменты

* полезные ссылки;
* отчёты об активности;
* генерация аудио и изображений;
* понятные приватные панели вместо запоминания длинных команд.

## Как читать справочник

У каждой инструкции есть обозначение доступа:

| Обозначение            | Для кого страница                          |
| ---------------------- | ------------------------------------------ |
| **Все участники**      | Действие не требует специальной роли       |
| **Сенатор**            | Нужна роль сенатора или более высокая роль |
| **Председатель**       | Управление пленарным консенсусом           |
| **Сотрудник SGL**      | Работа с кейсами и реестрами Бюро          |
| **Ответственное лицо** | Редкие исправления и служебные операции    |

Если вы впервые пользуетесь ботом, начните со страницы [Первые пять минут](start/first-steps.md).
