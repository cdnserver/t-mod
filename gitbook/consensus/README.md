# Пленарный консенсус

Начните со страницы [Consensus V3](v3.md), затем выберите руководство
[председателя](chair.md) или [участника](participant.md). Формула решений описана отдельно на
странице [«Как принимаются решения»](decision-rules.md), а безопасная тренировка доступна в
[симуляторе](simulator.md). Во время настоящего заседания ведущий может следовать готовому
[сценарию с кнопками, репликами и паузами](host-script.md).
