# Локальная веб-панель консенсуса

T-Mod поднимает отдельную read-only панель для администратора внутри домашней сети. Она показывает:

* текущий этап и ведущего заседания;
* кворум и подтверждение участников;
* таймер и количество полученных голосов;
* состояние четырёх блоков после фиксации результата;
* текущий законопроект и ссылку на оригинал;
* очередь следующих проектов и последние решения.

Во время активного голосования направления индивидуальных голосов не раскрываются. Администратор
видит только факт получения голоса. Это позволяет следить за техническим ходом заседания, не
влияя на ещё не завершившееся решение.

## Адрес и порт

По умолчанию Docker публикует панель на порту `8787`:

```text
http://IP_ДОМАШНЕГО_СЕРВЕРА:8787
```

Порт выбран отдельно от обычных сайтов и настраивается через `CONSENSUS_WEB_PORT`. Если он
меняется, такое же сопоставление порта нужно изменить в `docker-compose.yml`.

## Локальное имя `t.consensus`

На каждом компьютере, с которого нужна панель, откройте от имени администратора файл:

```text
C:\Windows\System32\drivers\etc\hosts
```

Добавьте строку, подставив локальный IPv4-адрес домашнего сервера из `ipconfig`:

```text
192.168.1.50 t.consensus
```

После этого панель открывается по адресу:

```text
http://t.consensus:8787
```

Запись `hosts` назначает имя, но не порт. Чтобы открывать просто `http://t.consensus`, существующий
локальный reverse proxy должен направлять это имя на `127.0.0.1:8787`.

## Вход

Панель защищена отдельным ключом. Администратор получает адрес и ключ в Discord:

1. откройте канал **«Настройки бота»**;
2. нажмите **«Веб-панель»**;
3. скопируйте скрытый ключ;
4. вставьте его на странице входа.

Если `CONSENSUS_WEB_TOKEN` не задан, T-Mod один раз создаёт сильный ключ и сохраняет его в
постоянной базе. Перезапуск контейнера ключ не меняет. Браузер хранит его только до закрытия
вкладки.

{% hint style="warning" %}
Панель предназначена только для домашней сети. Не настраивайте перенаправление порта `8787` на
роутере и не публикуйте ключ доступа.
{% endhint %}

## Запуск после обновления

Пересоберите контейнер, потому что добавилась веб-зависимость и новый порт:

```powershell
docker compose up -d --build
```

Если Windows спросит о сетевом доступе Docker Desktop, разрешите доступ только для частной сети.
Проверить запуск можно в логах контейнера по строке `Consensus web panel`.

## Если страница не открывается

Проверьте по порядку:

1. контейнер пересобран, а не только перезапущен;
2. в `docker-compose.yml` присутствует `8787:8787`;
3. `CONSENSUS_WEB_ENABLED=true`;
4. открывается `http://IP_СЕРВЕРА:8787`;
5. брандмауэр Windows разрешает входящие подключения к `8787` из частной сети;
6. IP в файле `hosts` совпадает с текущим IPv4 сервера.

Если страница по IP работает, а `t.consensus` нет, проблема только в локальном имени, а не в T-Mod.
