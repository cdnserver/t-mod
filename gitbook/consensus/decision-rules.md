# Как принимаются решения

На этой странице простыми словами объясняется подсчёт по Верховному акту Товарищества,
редакция III: четыре равных блока по `25%`.

## Кворум

В заседании должны подтвердиться:

* больше половины допущенного состава;
* не меньше **трёх участников**.

Присутствие конкретного сопредседателя не является отдельным условием кворума. Сначала T-Mod
определяет допущенный состав в голосовом канале, затем собирает личные подтверждения.

## Четыре равных блока

Общий результат состоит из четырёх независимых частей:

| Блок | Вес |
|---|---:|
| Первый сопредседатель | `25%` |
| Второй сопредседатель | `25%` |
| Третий сопредседатель | `25%` |
| Консенсус Товарищества | `25%` |

Личный блок принадлежит только одному из трёх закреплённых сопредседателей. Административный
доступ к ведению заседания сам по себе не создаёт дополнительный блок голоса.

## Внутренний консенсус Товарищества

Все подтверждённые участники одновременно участвуют во внутреннем голосовании. T-Mod считает
только голоса **«За»** и **«Против»**:

```
голоса «За» ÷ все валидные голоса «За» и «Против» × 100
```

Если одна позиция получила строго больше `50%`, блок консенсуса активируется в эту сторону.
При равенстве `50/50` блок остаётся неактивным.

Голос **«Воздержаться»** учитывается при участии и завершении голосования, но не входит в
знаменатель внутреннего `yes/no`.

## Единый порядок решений

Все законопроекты в очереди рассматриваются одинаково. Автор и ИИ-редактор не назначают проекту
особую категорию или дополнительный вес. Для принятия нужны голоса **«За»** как минимум от двух
из четырёх блоков, то есть `50%`.

{% hint style="warning" %}
Расклад `50% За / 50% Против` не считается принятием обычного решения. Проект отклоняется и при
необходимости выносится повторно отдельным законопроектом.
{% endhint %}

## Пример принятия

```
Первый сопредседатель                         = За 25%
Второй сопредседатель                        = Против 25%
Третий сопредседатель                        = За 25%
Внутренний консенсус: 4 За, 2 Против         = За 25%
Общий результат                              = 75% За / 25% Против
Решение                                      = принято
```

## Пример отклонения

```
Первый сопредседатель                         = За 25%
Второй сопредседатель                        = За 25%
Третий сопредседатель                        = Против 25%
Внутренний консенсус                         = Против 25%
Общий результат                              = 50% За / 50% Против
Решение                                      = не принято
```

## Изменение голоса и завершение

Пока голосование активно, участник может изменить позицию. T-Mod учитывает последний выбор.
Если проголосовали все подтверждённые участники, этап можно завершить сразу; иначе результат
фиксируется по команде ведущего или после таймера.

Версия правил замораживается в снимке заседания. Обновление бота не меняет формулу уже начатого
консенсуса.

## Дискуссия

Дискуссия временно приостанавливает голосование и таймер. Ранее поданные голоса сохраняются,
но после возвращения к голосованию участники могут изменить позицию.

## Протокол

В финальном сообщении перечисляются все рассмотренные проекты. Название проекта является ссылкой
на его исходную карточку, а длинный протокол автоматически делится на несколько сообщений без
обрезания списка.

Практические инструкции:

* [участнику](participant.md);
* [председателю](chair.md).
