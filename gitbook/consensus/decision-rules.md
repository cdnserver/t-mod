# decision rules

На этой странице простыми словами объясняется кворум, подсчёт голосов, дискуссия и вето.

## Кворум

Для начала и продолжения консенсуса нужны:

* минимум **2 председателя**;
* минимум **1 сенатор**;
* число сенаторов должно быть **нечётным**.

Сначала бот проверяет присутствующих в голосовом канале, затем — тех, кто подтвердил участие в ЛС.

## Две части результата

Решение складывается из голоса председателя и позиции активного сената.

### Голос председателя

Каждый председатель, проголосовавший **«За»**, добавляет `49%` к общему результату.

### Внутренний консенсус сенаторов

Бот считает долю голосов **«За»** среди сенаторов, которые успели проголосовать:

```
голоса сенаторов «За» ÷ все поданные голоса сенаторов × 100
```

Если результат строго выше `51%`, внутренний консенсус активируется и добавляет `2%`.

### Порог принятия

Проект принят, если общий результат достиг `51%`.

## Пример принятия

```
Один председатель «За»                         = 49%
Сенаторы: четыре «За», один «Против»           = 80%
Внутренний консенсус активирован               = +2%
Общий результат                                = 51%
Решение                                        = принято
```

## Пример отклонения

```
Один председатель «За»                         = 49%
Сенаторы: один «За», два «Против»              = 33,33%
Внутренний консенсус не активирован            = +0%
Общий результат                                = 49%
Решение                                        = не принято
```

{% hint style="warning" %}
При ручном завершении или окончании таймера сенаторы, которые не проголосовали, не входят в расчёт внутреннего процента. Ведущему важно проверить список ожидающих до фиксации результата.
{% endhint %}

## Изменение голоса

Пока голосование активно, участник может изменить позицию. Бот учитывает последний выбор. После публикации результата изменить голос обычной кнопкой уже нельзя.

## Автоматическое завершение

Если проголосовали все подтверждённые участники, бот завершает этап сразу. Таймер ждать не нужно.

## Дискуссия

Дискуссия не отменяет голоса. Она временно скрывает голосование, останавливает таймер и собирает позиции в отдельном канале. После завершения голосование возвращается, а участники могут сохранить или изменить свою позицию.

## Вето

Право вето есть только у постоянного председателя. Вето требует отдельного подтверждения.

После него:

1. Голосование немедленно заканчивается.
2. Итог сохраняется как вето.
3. Бот создаёт повторную попытку проекта с новым номером, если это возможно.
4. История первоначального рассмотрения остаётся в протоколе.

## Почему заседание может остановиться

Если подтверждённые участники покидают голосовой канал и кворум нарушается, бот автоматически ставит консенсус на паузу. Это защищает решение от продолжения неполным составом.
