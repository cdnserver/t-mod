# commands

Основные действия доступны кнопками. Эта страница нужна как короткий справочник быстрых команд.

## Главные меню

| Команда | Что открывает                                    | Где работает                    |
| ------- | ------------------------------------------------ | ------------------------------- |
| `/tvrs` | Универсалитет Товарищества                       | Любой серверный канал           |
| `/market` | Поиск предметов, авто, одежды и цен RU15 | Любой серверный канал           |
| `/profile` | Личный профиль, статус и персонажи | Любой серверный канал |
| `/sg`   | Панель SGL или карточку указанного кейса/клиента | Командный центр или канал кейса |

## Казна, крафты и аудит

| Команда          | Назначение                                          |
| ---------------- | --------------------------------------------------- |
| `/finance`       | Быстро открыть казну в финансовом канале            |
| `/craft`         | Быстро открыть центр крафтов в канале крафтов       |
| `/actions`       | Посмотреть журнал действий и их ID                  |
| `/undo`          | Безопасно отменить последнее или указанное действие |
| `/finance-audit` | Найти финансовую операцию                           |
| `/finance-stats` | Посмотреть статистику казны                         |
| `/craft-stats`   | Посмотреть статистику производства и продаж         |

Все эти возможности также собраны в `/tvrs`.

## Рынок RU15

| Команда | Назначение |
| ------- | ---------- |
| `/market` | Открыть личное рыночное меню |
| `/market query:железная руда` | Сразу найти предмет по русскому названию |
| `/market query:#39` | Открыть предмет по Majestic itemId |
| `/market category:Автомобили query:пегасси` | Найти авто по русскому написанию марки |
| `/market category:Одежда query:сумка` | Найти все подходящие варианты одежды |

Параметр `category` и список в самом меню переключают между предметами, автомобилями и одеждой. При вводе `query` Discord предлагает подсказки из выбранного локального каталога T-Mod.
В карточке любой рыночной позиции кнопка **«Настроить сигнал»** создаёт личное одноразовое уведомление по цене
и количеству, а кнопка **«Мои сигналы»** открывает управление ими.

## Законопроекты и консенсус

| Команда         | Для чего                                     | Доступ                                 |
| --------------- | -------------------------------------------- | -------------------------------------- |
| `/tvrs`         | Очередь, законопроекты и пленарная панель    | Все; панель консенсуса — председателям |
| `/tvrs_setbill` | Исправить счётчик следующего проекта         | Председатель                           |
| `/tvrs_sticky`  | Восстановить карточку подачи проектов        | Председатель                           |
| `/tvrs_admin`   | Просмотреть или исправить сохранённый проект | Председатель                           |

## SGL Bureau

| Команда         | Для чего                                  |
| --------------- | ----------------------------------------- |
| `/sg`           | Центральная панель, пользователь или кейс |
| `/sg_addnews`   | Оформить новость Бюро                     |
| `/sg_initiate`  | Подготовить стартовые каналы и нумерацию  |
| `/sg_registry`  | Найти клиента или адвоката                |
| `/sg_lawyeradd` | Добавить или обновить профиль адвоката    |
| `/sg_admin`     | Редкое ручное исправление записи          |
| `/sg_restore`   | Временно открыть архив по номеру кейса    |

Большинство ежедневных операций SGL выполняется кнопками внутри `/sg`, поэтому старые отдельные команды создания, ссылки на иск и закрытия дела больше не нужны.

## Общие инструменты

| Команда                      | Назначение                               |
| ---------------------------- | ---------------------------------------- |
| `/profile`                   | Открыть свой профиль и персонажей        |
| `/profile user:@Участник`    | Посмотреть профиль другого участника     |
| `/l`, `/link`, `/л`, `/линк` | Получить ссылки Бюро и Товарищества      |
| `/activity`                  | Активность роли или история пользователя |
| `/sgl`                       | Проверить, отвечает ли бот               |
| `/sglaudio`                  | Создать AI-аудио                         |
| `/zigmund`                   | Создать AI-изображение                   |

## Примеры

```
/actions module:craft
/undo action_id:184 reason:Неверно указал количество
/activity type:tvrs user:@Участник
/market query:железная руда
/market category:Автомобили query:пегасси
/profile user:@Участник
/sg user:@Клиент
/sg case:90
```

{% hint style="success" %}
Не обязательно запоминать параметры. Введите `/`, выберите команду — Discord сам покажет поля и подсказки.
{% endhint %}
