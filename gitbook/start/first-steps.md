# first steps

Эта страница поможет быстро освоиться, даже если вы раньше не пользовались Discord-ботами.

**Для кого:** все участники сервера.

{% stepper %}
{% step %}
## Откройте список команд

В любом текстовом канале Discord введите символ `/`. Discord покажет доступные команды бота.

Два главных центра:

* `/tvrs` — Товарищество, казна, крафты, аудит, законопроекты и консенсус;
* `/sg` — клиентские дела и инструменты SGL Bureau.

После выбора команды нажмите Enter. Если у команды есть параметры, Discord сам покажет поля.
{% endstep %}

{% step %}
## Не пугайтесь приватных ответов

Сообщение с пометкой **«Видно только вам»** не появляется у остальных. Так работают главные меню, формы поиска, статистика и подтверждения.

Публично бот отправляет только то, что должно быть общим: карточки законопроектов, планы крафтов, журналы, результаты голосований и сообщения в клиентском кейсе.
{% endstep %}

{% step %}
## Разрешите личные сообщения

Личные сообщения особенно важны для пленарного консенсуса и подтверждения некоторых действий.

1. Откройте настройки приватности нужного сервера.
2. Разрешите личные сообщения от участников сервера.
3. Убедитесь, что бот не находится в списке заблокированных.

{% hint style="warning" %}
Если ЛС закрыты, бот не сможет прислать приглашение на консенсус или карточку голосования.
{% endhint %}
{% endstep %}

{% step %}
## Выберите нужный раздел

| Ситуация                             | Что открыть                   |
| ------------------------------------ | ----------------------------- |
| Нужно записать снятие или пополнение | `/tvrs` → **Казна**           |
| Нужно создать или продолжить крафт   | `/tvrs` → **Крафты**          |
| Нужно найти или отменить действие    | `/tvrs` → **Аудит**           |
| Нужно подать законопроект            | `/tvrs` → **Законопроекты**   |
| Пришло приглашение на голосование    | Откройте ЛС бота              |
| Нужно открыть клиентский кейс        | `/sg` в командном центре Бюро |
| Бот не отвечает                      | `/sgl`                        |
{% endstep %}

{% step %}
## Всегда читайте итог бота

После формы бот сообщает, что именно сохранено. В финансовых и производственных действиях он также показывает ID записи — по нему действие можно найти и, если разрешено, отменить.

Если что-то пошло не так, не отправляйте одну и ту же форму много раз. Откройте свежую панель и загляните в [решение частых проблем](../troubleshooting.md).
{% endstep %}
{% endstepper %}

## Ваша короткая памятка

```
/tvrs  — дела Товарищества
/sg    — дела Бюро
/sgl   — проверить, отвечает ли бот
ЛС     — приглашения и голосование
Назад  — вернуться в главное меню
```
