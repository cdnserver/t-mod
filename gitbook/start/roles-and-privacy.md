# roles and privacy

Бот показывает только те действия, которые подходят вашей роли и месту работы.

## Что видят другие

| Вид ответа               | Кто его видит                          |
| ------------------------ | -------------------------------------- |
| Приватная панель Discord | Только пользователь, который её открыл |
| Постоянная панель управления | Карточку видят все, ответы на кнопки — только нажавший |
| Личное сообщение бота    | Только получатель                      |
| Общая карточка           | Все участники с доступом к каналу      |
| Приватный канал кейса    | Клиент и назначенные сотрудники SGL    |
| Канал дискуссии          | Участники с разрешёнными ролями        |

Чужой пользователь не может управлять вашей приватной панелью. Если он увидит старое сообщение на скриншоте, кнопки всё равно останутся привязаны к владельцу панели.

## Роли Товарищества

| Роль                    | Основные возможности                                               |
| ----------------------- | ------------------------------------------------------------------ |
| Участник                | Казна, крафты, свой аудит, статистика, просмотр очереди            |
| Сенатор                 | Предложение проектов, участие в консенсусе, голосование, дискуссия |
| Председатель            | Всё выше, а также запуск и ведение консенсуса                      |
| Постоянный председатель | Возможности председателя и право вето                              |
| Администратор Discord   | Служебный доступ к защищённым операциям                            |

Если у человека одновременно роли сенатора и председателя, в консенсусе он учитывается как председатель.

## Роли SGL Bureau

| Роль                  | Основные возможности                                      |
| --------------------- | --------------------------------------------------------- |
| Клиент                | Доступ к своему кейсу, ввод данных и подтверждений оплаты |
| Ведущий адвокат       | Ведение дела, иск, чеки, договор и закрытие               |
| Секретарь             | Помощь в ведении и закрытии дела                          |
| Сотрудник SGL         | Центральная панель, реестры и служебные действия          |
| Администратор Discord | Служебный доступ к инструментам Бюро                      |

## Почему действие может быть недоступно

Обычно причина одна из четырёх:

1. Действие открыто вне сервера или исходный канал недоступен.
2. У пользователя нет нужной роли.
3. Процесс уже перешёл на следующий этап.
4. Панель устарела после перезапуска или завершения действия.

Бот старается объяснить ограничение приватным сообщением и указать правильный канал или роль.

{% hint style="info" %}
`/tvrs`, `/finance` и `/craft` можно открывать в любом серверном канале. Общие карточки всё равно попадают в свои отсеки операционного центра, а `#активные-задачи` даёт ссылки на то, что требует внимания.
{% endhint %}

## Работа с чужими действиями

Обычный участник видит и отменяет только свои записи. Финансовый администратор или администратор сервера может проверять и исправлять действия другого пользователя. Любая отмена сохраняет автора, время и причину — история не исчезает.

Подробнее: [Аудит и отмена](../tvrs/audit.md).
