# glossary

| Термин                   | Значение                                                                   |
| ------------------------ | -------------------------------------------------------------------------- |
| **Универсалитет**        | Главное приватное меню Товарищества, открываемое командой `/tvrs`          |
| **Казна**                | Общие денежные средства Товарищества                                       |
| **Сверка**               | Запись фактической суммы или содержимого склада                            |
| **Межотчёт**             | Внеплановая фиксация реального остатка казны                               |
| **Действие**             | Изменение данных бота, которому может быть присвоен ID                     |
| **Компенсация**          | Новая запись, которая безопасно отменяет результат предыдущего действия    |
| **Рецепт**               | Требования к одной попытке крафта: материалы, деньги, время и размер цикла |
| **План крафта**          | Полный производственный процесс с выбранным рецептом и количеством попыток |
| **Цикл**                 | Одна поставленная в игре партия производства                               |
| **Законопроект**         | Предложение, вынесенное на рассмотрение Товарищества                       |
| **Консенсус**            | Заседание с регистрацией, голосованием и итоговым протоколом               |
| **Кворум**               | Минимальный подтверждённый состав для проведения заседания                 |
| **Внутренний консенсус** | Результат голосования сенаторов                                            |
| **Вето**                 | Право постоянного председателя остановить принятие текущего проекта        |
| **Sticky-карточка**      | Сообщение подачи проектов, которое бот поддерживает внизу канала           |
| **Кейс**                 | Приватное клиентское дело SGL Bureau                                       |
| **Ведущий адвокат**      | Основной сотрудник, отвечающий за конкретный кейс                          |
| **Чек**                  | Карточка стоимости услуг, пошлины и подтверждений оплаты                   |
| **Статик**               | Постоянный игровой идентификатор персонажа                                 |
| **Приватная панель**     | Ответ Discord, видимый только вызвавшему пользователю                      |
| **Общая карточка**       | Сообщение в рабочем канале, доступное всей уполномоченной группе           |
| **ID действия**          | Числовой номер записи для поиска и безопасной отмены                       |
