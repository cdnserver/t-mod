# sgl care

Служебные инструменты SGL предназначены для сотрудников Бюро и администраторов.

## Сначала используйте обычную панель

Большинство ошибок можно исправить через:

```
/sg case:<номер> → Редактировать
/sg user:@Клиент
/tvrs → Аудит → Отменить
```

Ручная команда `/sg_admin` нужна для записей, которые нельзя безопасно исправить обычной кнопкой.

## Просмотр

Перед любым изменением откройте запись:

```
/sg_admin target:case action:view identifier:090
/sg_admin target:client action:view identifier:12
/sg_admin target:lawyer action:view identifier:3
/sg_admin target:receipt action:view identifier:14
```

Типы записей:

| Тип       | Что хранит                      |
| --------- | ------------------------------- |
| `case`    | Клиентское дело и его состояние |
| `client`  | Профиль клиента                 |
| `lawyer`  | Профиль адвоката                |
| `receipt` | Чек и подтверждения оплаты      |

## Изменение

Пример исправления статуса и телефона:

```
/sg_admin target:case action:edit identifier:090 field:status value:closed
/sg_admin target:client action:edit identifier:12 field:phone value:86549072
```

Меняйте одно поле за раз, затем снова выполняйте `view`. Особенно внимательно проверяйте Discord ID, номер канала, суммы, связи кейса и чека.

Чтобы очистить необязательное поле, можно использовать значение `null`.

{% hint style="warning" %}
Ручное изменение записи не гарантирует обновление старых сообщений Discord. Название канала кейса бот постарается синхронизировать, но опубликованные карточки могут остаться историческими.
{% endhint %}

## Удаление

```
/sg_admin target:case action:delete identifier:090 confirm:DELETE
```

При удалении кейса могут исчезнуть связанная история, чеки и сам канал Discord. Операция необратима обычной кнопкой.

Перед удалением:

1. Убедитесь, что выбран правильный номер.
2. Сохраните нужные документы и материалы.
3. Проверьте связанные чеки.
4. Получите согласование ответственного лица.
5. Только затем подтвердите `DELETE`.

## Если ошиблись в чеке

Не подтверждайте неверный платёж. Откройте чек через `view`, исправьте нужное поле либо удалите ошибочный чек и создайте новый через панель кейса. После этого убедитесь, что сумма в договоре совпадает с актуальным чеком.

## После исправления

```
□ Запись повторно проверена через view
□ Канал кейса имеет правильное название
□ Клиент и сотрудники сохранили доступ
□ Актуальная карточка открывается через /sg
□ В рабочих сообщениях указано, что было исправлено
```
