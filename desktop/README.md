# T-Mod Desktop

Единая защищённая оболочка для Reactor, Consensus, Atlas, SGL, ОВР, Games и административного контура T-Mod.

## Что уже работает

- единая постоянная авторизация для всех доменов `*.tvr.lat`;
- главный экран с центром внимания, уведомлениями и доступными пространствами;
- встроенное открытие сервисов без ухода из приложения;
- командная строка `Ctrl/Cmd + K` и горячие переходы;
- автоматическое обновление лёгкой сводки без перезагрузки открытого сервиса;
- учёт уровня аккаунта, членства в Товариществе и секционных доступов;
- безопасная изоляция удалённых страниц от Node.js и от локальной оболочки;
- автоматическая проверка, фоновая загрузка и установка новых версий;
- сборки Windows (NSIS), macOS (DMG) и Linux (AppImage).

При запуске приложение проверяет открытый канал релизов, загружает новую версию в фоне и предлагает безопасный перезапуск. Исходный репозиторий при этом остаётся закрытым.

## Разработка

Нужен Node.js 22+ и pnpm 11.

```bash
cd desktop
pnpm install
pnpm dev
```

Проверки и production-сборка:

```bash
pnpm test
pnpm typecheck
pnpm build
pnpm dist
```

Готовые установщики появляются в `desktop/release/`.

## Выпуск новой версии

1. Изменить `version` в `desktop/package.json` и обновить lock-файл.
2. Закоммитить изменения в `main`.
3. Создать и отправить тег той же версии: `desktop-v0.2.0`.
4. GitHub Actions проверит код, отдельно соберёт Windows, macOS и Linux и опубликует файлы в открытом репозитории `cdnserver/t-mod-releases`.

Для публикации в приватном репозитории исходного кода нужен Actions secret `DESKTOP_RELEASE_TOKEN` с правом записи релизов в `cdnserver/t-mod-releases`. Windows-сборка без коммерческого сертификата устанавливается и обновляется, но SmartScreen может показать предупреждение о неизвестном издателе. Для распространения macOS без системных предупреждений потребуется Apple Developer signing и notarization.

## Модель безопасности

Локальный интерфейс получает только безопасную сводку аккаунта. HttpOnly-cookie остаётся в постоянной сетевой сессии Electron и не раскрывается React-интерфейсу. Удалённые страницы работают с `sandbox`, `contextIsolation`, без Node.js; переходы ограничены HTTPS-доменами T-Mod, запросы разрешений блокируются.

Версия desktop-протокола начинается с `1`; новые поля backend может добавлять без поломки старых клиентов.
