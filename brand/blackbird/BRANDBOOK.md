# BLACKBIRD

Цифровая система «Технологий Товарищества».

Blackbird сочетает строгую институциональность, космический масштаб и ощущение точного закрытого инструмента. Это не игровой sci-fi и не неоновый киберпанк: визуальный язык строится на тёмном пространстве, холодном металле, чистой сетке и одном сигнале.

## 1. Архитектура бренда

### Мастер-знак

Чёрная птица проходит перед затмением и касается точки-звезды. Только мастер-знак Blackbird может содержать птицу, затмение и планетарный диск.

### Сервисные знаки

Каждый сервис получает один простой предметный символ. В них запрещены птица, планеты, затмения и орбитальные кольца. Семью объединяют чёрный металл, серебряная кромка и одна холодная точка состояния.

| Контур | Символ | Смысл |
| --- | --- | --- |
| Atlas | четырёхлучевой компас | направление и интеллект |
| Consensus | три места и точка кворума | равенство и решение |
| SGL | суд и весы | право и защита |
| Reactor | защищённая капсула | личный контур |
| ОВР | щит и апертура | проверка и наблюдение |
| Games | шахматный конь | стратегия |
| Задачи | путь и отметка | совместный прогресс |
| Ядерный Reactor | контейнмент и управляющие рельсы | контроль системы |

## 2. Цвет

Основные цвета не заменяются произвольными оттенками.

| Токен | HEX | Назначение |
| --- | --- | --- |
| Void | `#020407` | основной фон |
| Ink | `#05070A` | чёрный знак и плотные поверхности |
| Graphite | `#11161D` | панели второго уровня |
| Steel | `#697785` | вторичный текст |
| Silver | `#DDE8F0` | контуры и разделители |
| Frost | `#F5FAFD` | основной текст |
| Signal | `#BCEBFF` | активная точка и фокус |
| Live | `#73E0B1` | успешное состояние |

Цвета состояния не окрашивают весь логотип. Они применяются к точке, короткому индикатору или интерфейсному сообщению.

## 3. Типографика

- `Unbounded 500/600` — названия продукта, крупные заголовки, номера сцен.
- `Manrope 400/500/600/700` — интерфейс, документы и подписи.
- Заголовки набираются плотнее обычного (`-0.03em`…`-0.06em`).
- Служебные подписи набираются прописными с разрядкой (`0.12em`…`0.18em`).
- Длинные тексты не набираются Unbounded.

## 4. Охранное поле и размеры

- Охранное поле мастер-знака: не менее `12.5%` ширины изображения с каждой стороны.
- Охранное поле сервисного знака: не менее `10%`.
- Мастер fullcolor: минимум `48 px`.
- Сервис fullcolor: минимум `32 px`.
- Ниже этих размеров используется mono-вариант.
- Favicon: специально экспортированные `16/32 px`, без внешних подписей.

## 5. Фоны

- Fullcolor используется на `Void`, `Ink` или спокойной фотографии с затемнением не менее 72%.
- White mono использует световой контур птицы и применяется на тёмных фонах.
- Black mono использует тот же контур на белом, Frost и в печатных материалах.
- Ни один mono-знак не заливается по общему альфа-силуэту: птица, грани и внутренний рисунок каждого сервиса должны оставаться читаемыми.
- Нельзя помещать знак на активный градиент, цветной шум или фотографию без защитной подложки.

## 6. Интерфейс

- Базовая сетка: `8 px`; ключевые секции — `24/32/48 px`.
- Радиусы сдержанные: `2 px` для управления, `4 px` для панели, `6 px` для диалога.
- Стекло используется только для верхнего слоя; основные поверхности почти непрозрачны.
- Основная навигация монохромная. Активность обозначается светом, тонкой линией и яркостью, не радугой сервисных цветов.
- Иллюстрации не конкурируют с данными: один крупный образ на сцену.

## 7. Motion

- Быстрый отклик: `160 ms`.
- Стандартный переход: `260 ms`.
- Кинематографическое появление: `900 ms`.
- Фоновый цикл: от `9 s`, без заметного шва.
- Движение подчиняется направлению полёта птицы: слева вниз — вправо вверх.
- Запрещены бесконечное вращение радара, резкие белые вспышки и постоянный параллакс всех слоёв.

## 8. Звук

- Короткий воздушный импульс, мягкий металлический резонанс, спокойный низкий хвост.
- Без писка, сирены, громкого саб-удара и игрового «whoosh».
- Звук запуска должен иметь пики не выше `-6 dBFS`, UI-сигналы — не выше `-12 dBFS`.

## 9. Именование

- Продукт: `BLACKBIRD` в интерфейсных метках, `Blackbird` в тексте.
- Полное имя: `BLACKBIRD — Технологии Товарищества`.
- Не используется: `Black Bird`, `BlackBird`, `LUMEN`.
- Сервисные имена сохраняют собственное написание: `Atlas`, `Consensus`, `SGL`, `ОВР`, `Games`, `Reactor`.

## 10. Экспорт

`exports/<variant>/<mark>/<mark>-<size>.png`

Варианты: `fullcolor`, `white`, `black`, `ice`. Размеры: `16`, `24`, `32`, `48`, `64`, `128`, `256`, `512`, `1024`.

Дополнительно доступны favicon PNG, Windows ICO и macOS ICNS в ресурсах приложения. Все PNG сохраняют прозрачность.
