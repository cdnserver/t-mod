# T-Mod Media Kit

Единая визуальная система экосистемы T-Mod. Знаки построены на общей идее:
тёмная технологичная плоскость, световой горизонт и собственный символ сервиса.

## Состав

- `tmod/mark.svg` — основной знак T-Mod;
- `tmod/wordmark-horizontal.svg` — основной горизонтальный логотип;
- `tmod/mark-mono-*.svg` — светлый и тёмный монохром;
- `tmod/mark-windows-transparent.svg` — знак с прозрачными внешними углами для Windows `.ico`;
- `services/*.svg` — цветные векторные знаки сервисов 128×128;
- `services/mono/*.svg` — монохромные знаки без фоновой плитки;
- `exports/` — готовые PNG 24, 32, 64, 128 и 256 px;
- `tokens.json` — названия, цвета и назначение сервисов;
- `tmod-media-kit.css` — готовые CSS-переменные;
- `preview.html` — локальный каталог всего набора.

## Правила

1. Не перекрашивать отдельные части знака: используется фирменный цвет сервиса.
2. Минимальный размер знака — 24 px, рекомендуемый — 40 px и больше.
3. Вокруг знака оставляется свободное поле не меньше четверти его ширины.
4. Название набирается `Unbounded`, интерфейсный текст — `Manrope`.
5. На светлом фоне знак размещается на фирменной тёмной плитке без удаления фона.

SVG остаются основными исходниками: они одинаково резкие в приложении, на сайте,
в документах и при подготовке изображений для Discord.

Главный знак T-Mod — буква `T` внутри вертикального стеклянного модуля. Он
обозначает единое защищённое пространство, в котором собраны сервисы
экосистемы. Круговые орбиты и «радарные» мотивы не относятся к фирменному стилю.

Atlas использует картографический глобус с путеводной звездой, SGL — фасад
суда с весами в фронтоне. Эти смыслы нельзя заменять буквенными монограммами.
# Технологии Товарищества

Минималистичный знак и основной горизонтальный логотип: `tmod/technologies-mark.svg` и `tmod/technologies-wordmark.svg`.
Для заголовка используется `Unbounded`, для интерфейсного текста экосистемы — `Manrope`.
