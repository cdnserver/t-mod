BEAT SYNC DEMO ДЛЯ DAVINCI RESOLVE

В проекте:
- 24 секунды, 1920x1080, 60 fps;
- музыка 120 BPM;
- 48 смен кадров — по одной на каждый удар;
- 48 маркеров Beat 01 ... Beat 48;
- исходное видео: artifacts/t-mod-gource-1080p60.mp4.

Как открыть:
1. Запусти DaVinci Resolve.
2. Выбери File > Import Timeline > Import AAF, EDL, XML.
3. Открой Beat_Sync_Demo.fcpxml.
4. Если клипы будут Offline, укажи Resolve файл artifacts/t-mod-gource-1080p60.mp4.
5. Музыка лежит рядом с XML: sync_demo_music.wav.

После импорта можно выбрать File > Export Project и сохранить нативный файл .drp.
Готовое видео для быстрого просмотра: Beat_Sync_Demo_preview.mp4.
Таблица всех точек синхронизации: BEAT_MAP.txt.
